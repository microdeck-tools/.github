# MicroDeck.tools

**Fast, private, browser-based micro-tools for everyday workflows.**

🌐 **Website:** [https://microdeck.tools](https://microdeck.tools)

---

### ✨ About MicroDeck

**MicroDeck.tools** is a collection of lightweight, single-purpose web utilities designed to get things done quickly without bloat, sign-ups, or server-side tracking. 

Most tools on MicroDeck run **100% client-side** directly inside your browser using modern web technologies—meaning your files and data never leave your device.

### 🛠️ Core Principles

* **Privacy-First by Design:** Local processing in your browser ensures sensitive files stay on your machine.
* **Instant & Zero Friction:** No accounts, no paywalls, and no unnecessary steps—open a tool and start working immediately.
* **Lightweight & Responsive:** Built for speed across desktop and mobile devices.
